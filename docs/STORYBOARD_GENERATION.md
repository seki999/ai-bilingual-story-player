# 分镜规划

日常制作时，将对白交给 Codex 规划镜头和生成插画，随后在播放器导入故事 ZIP。以下说明播放器本地规划分镜时使用的算法。

解析器容许多个 Speaker 块、多行发言和不同冒号。发言以短句与部分复合动作边界切分，括号释义留在相邻片段。生成字幕保留台词原文，源对话单独保存。

本地对齐通过动态规划在两种语言内部维持顺序，候选包括一对一、一对多、多对一和空缺。分数结合双语概念词、原文词汇重叠和长度比，还会对缺乏配对证据的合并片段降权。对齐依据有限时可在编辑器查看置信度并调整。可选 LLM 结果必须完整覆盖所有片段、维持各语言顺序，并通过角色身份验证。

分镜以语义组为单位，由预计时长、密度、镜头数上限与图片预算决定镜头数量。动作、语气及地点线索决定提示词中的镜头、表情和场景。预设词表之外的故事仍会生成分镜，其提示词更依赖原文和用户编辑。人物设定带入每个镜头的文字提示；可为非默认角色、道具和人物补充参考图。

重新规划会创建新项目，旧版本继续可访问。单镜头修改或替换保留其他画面与其资源 ID。
