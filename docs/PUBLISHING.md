# Codex 故事发布流程

1. 将用户提供的原始对白保存到工作临时目录，确定标题和未使用的英文 slug。
2. 在项目根目录运行 `npm run story:publish -- plan <对白.txt> "<标题>"`。按输出编号生成相应插画，以 `scene-01.webp` 等名称保存到同一临时目录。
3. 运行 `npm run story:publish -- add <对白.txt> "<标题>" <slug> <插画目录>`。脚本会检查每个镜头都有插画，生成内容带哈希的资源文件，并更新 `public/stories/index.json`。
4. 检查对白、分镜与图像的对应关系，提交 `public/stories/` 并推送到 `main`。等 Pages 部署成功后，在「项目库 → 已发布故事」验证故事可以打开和播放。

站点按需加载公开故事资源。播放器会校验资源哈希并保存本地副本。发布文件是应用内部使用的传输格式，访问者直接点击故事即可。发布内容可供公众访问。
