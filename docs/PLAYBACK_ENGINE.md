# 播放引擎

`makeTimeline` 从字幕、语言模式、顺序和跟读参数建立逻辑时间轴。图片由当前字幕的 sceneId 决定，双语配对共享镜头。切换语言优先恢复同一对照组和镜头。找不到对应语言时回到该模式开头。

引擎状态包括 idle、preparing、playing、paused、seeking、completed 和 error。真实媒体开始、结束与错误控制状态，单调播放版本使过期回调失效。暂停时驱动原生暂停，跟读间隔冻结，逻辑时钟保持当前值。

系统语音依靠逐段 utterance 及浏览器提供的 boundary 事件。在缺少 boundary 时保持句子级同步，进度在段落边界更新。HTML Audio 以 timeupdate 读取媒体时钟，并在 ended 时推进。进度条在上传音频段内按媒体时钟跳转，系统朗读回到目标字幕起点。已缓存音频可导出，系统语音只保存配置。

TtsProvider 是媒体驱动接口。未来生成实际配音的服务可返回可保存音频与可选时间戳，再由播放器选择对应驱动。
